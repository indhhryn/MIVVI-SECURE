# Prototype Alignment

This Android implementation carries forward the MIVVI SECURE prototype's luxury cosmic direction and agreed product behavior.

## Visual direction

- Cosmic Black `#080A18`
- Midnight Navy `#10162D`
- Deep Indigo `#1A2146`
- Royal Violet `#6852E8`
- Aurora Cyan `#63DDE8`
- Pearl White `#F5F5FC`
- Muted Text `#A8B0C8`
- 8-point spacing rhythm, dark cards, subtle borders, rounded surfaces

## Screen/function coverage in the runnable prototype

- Welcome / guest entry, Login UI, Sign Up UI, Forgot Password UI
- Beranda
- Hubungkan Notifikasi / Android Notification Access settings
- Analisis Manual
- Hasil Analisis
- Aktivitas Notifikasi
- Riwayat Analisis and detail
- Edukasi Keamanan and article dialogs
- Pengaturan, trusted senders, selected notification sources, API URL and rule sync

Several Figma pages become states or dialogs rather than separate Android Activities. For example, history detail and article detail are opened from their parent screen.

## Claims intentionally not carried into implementation

No neural engine, AES claim, zero cloud logs, real-time interception label, automatic blocking, threat mitigation, or made-up latency/telemetry. The authentication pages are UI-only until an actual account service is designed and secured.
